HOME PAGE SLIDESHOW PHOTOS
==========================
Put the photos you want in the big slideshow on the home page into THIS folder
(assets/slideshow). The website shows exactly these photos, in file name order.

  - Order: rename the files 01-..., 02-..., 03-... to choose the order.
        01-sports-day.jpg  ->  first
        02-science-fest.jpg ->  second
  - Up to 12 photos are shown. Extra photos are ignored.
  - Best size: landscape (wider than tall), about 1600 x 900 pixels (16:9), under 1 MB each.
    The slideshow frame is 16:9, so other shapes are cropped to fit.
  - Allowed endings: .jpg .jpeg .png .webp .gif .avif
  - Photos must sit directly in this folder (no folders inside it).
  - This folder is empty of photos? Then the slideshow shows the 6 newest event photos, as before.
  - Do not delete this README.txt. It keeps the folder on GitHub when no photos are inside.
  - Changes show on the website 1 to 2 minutes after you commit on GitHub.

HOW TO UPLOAD (GitHub website)
  1. Open your repository on github.com, then open the folder  assets > slideshow.
  2. Click  Add file > Upload files, then drag your photos in.
  3. Press  Commit changes.
  To remove a photo: open it, click the three dots (...) > Delete file > Commit.

NOT USING GITHUB PAGES?
  - Number the photos 1.jpg, 2.jpg, 3.jpg ... (no gaps) inside this folder, or
  - list them in assets/js/events-data.js (see the note at the top of that file).
